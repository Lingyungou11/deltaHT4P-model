# δHT4P model

This repository contains the code and raw observed data for the deltaHT4P model, with the Barrow site used as a representative example.

## Repository structure
- `DM_application_surface_Barrow site`: source code for differentiable modeling
- `Initial condition (Barrow)`: initial condition data for heat transfer simulation
- `T_soil data (Barrow site)`: observed soil temperature data
